# 产品

## 目标

一个供维护者自己使用的浏览器扩展。每个新能力都做成独立模块，方便逐步扩展。

## 第一版范围

## 决定（维护者，2026-11-15）

| 决定 | 理由 | 被否决的选项及原因 |
| --- | --- | --- |
| 把任意语言的网页翻译成配置好的目标语言。 | 未单独说明。 | 未说明 |
| 两种显示模式：对照（原文加译文）和替换（只显示译文）。两种模式共用同一条翻译流程，切换模式不重新请求翻译。 | 切换显示模式不需要重新请求，不花钱，立即完成。 | 做成两个独立功能：会重复请求和重复代码 |
| 默认显示模式为对照。 | 维护者的使用习惯，未单独说明其他原因。 | 未说明 |
| 由用户提供自己的 API key。 | 项目为个人使用设计，没有也不打算运营服务器。 | 提供托管的翻译后端：需要运营成本和账号体系 |
| 第一版使用 OpenAI 兼容的 Chat Completions API。 | 多数厂商和中转服务都兼容，一套代码即可。 | 第一版就为各厂商写专用适配：工作量大且暂无需求 |
| 只支持 Chrome。 | 维护者只用 Chrome。 | 第一版同时支持多个浏览器：测试成本成倍增加 |

## 第一版不做

- 划词翻译
- 发送到 Notion
- MCP 客户端
- 按站点自动翻译
- 持久化的翻译缓存
- PDF 和视频字幕
- 针对特定服务商的适配器
- 在译文中保留行内链接和格式

## 之后的方向

- 划词操作
- 把选中文本发送到 Notion
- 通用 MCP 客户端
