# 产品

## 目标

一个供维护者自己使用的浏览器扩展。每个新能力都做成独立模块，方便逐步扩展。

## 第一版范围

## 决定（维护者，2026-11-15）

- 把任意语言的网页翻译成配置好的目标语言。
- 两种显示模式：对照（原文加译文，默认）和替换（只显示译文）。两种模式共用同一条翻译流程，切换模式不重新请求翻译。
- 由用户提供自己的 API key。
- 第一版使用 OpenAI 兼容的 Chat Completions API。
- 只支持 Chrome。

## 第一版不做

- 划词翻译
- 发送到 Notion
- MCP 客户端
- 按站点自动翻译
- 持久化的翻译缓存
- PDF 和视频字幕
- 针对特定服务商的适配器
- 在译文中保留行内链接和格式

## 之后的方向

- 划词操作
- 把选中文本发送到 Notion
- 通用 MCP 客户端
